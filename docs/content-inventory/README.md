# Content & Media Inventories

Point-in-time data exports and planning sheets for CMS content and media. These are
reference artifacts — not build inputs (no code or script reads them).

| File | What it is |
|------|------------|
| `CleanStart-Prod-Media-Inventory.xlsx` | Snapshot of prod CMS media (all/unused media + per-collection image usage). Backed the media-filename cleanup (rollout checklist #11). |
| `CleanStart-Guides-Inventory.xlsx` | Inventory of the imported `guides` collection. |
| `CleanStart-Guides-Image-Request.xlsx` | Guides still missing a cover image. |
| `cms-content-recommendations.xlsx` | Editorial plan — blog/guide/news clusters and ordering. |
| `newsroom-data.xlsx` | Newsroom seed/planning data (title, URL, date, region). |

Web-facing reports (CTA inventory, image audit, SEO audit) live in [`../web/`](../web/).
