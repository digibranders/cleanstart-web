# GTM container source

`cleanstart-container.json` is the tag configuration for container
`GTM-TBDDZW9K` (cleanstart.com), in GTM's own import/export format. It is kept
in the repo so the container is reviewable in a pull request rather than living
only in the GTM UI.

It is a **starting point, not a live mirror**. GTM remains the source of truth
once published. If you change the container in the UI, export it again
(Admin, Export Container) and update this file in the same pull request.

## What it contains

| Entity | Count | Notes |
|---|---|---|
| Tags | 12 | 1 Google tag (GA4 `G-S6T47D7PZR`), 9 GA4 event tags, Apollo.io, Leadfeeder |
| Triggers | 11 | 9 Custom Event triggers matching `lib/analytics/track.ts`, 2 consent triggers |
| Variables | 17 | One Data Layer Variable per event parameter, plus 2 consent flags |

Microsoft Clarity is **not** included: it needs a Clarity project id that did
not exist when this was written. Add it as described in
`docs/web/TRACKING-TAGS.md`, triggered on `CE - consent performance granted`.

## How to import

1. GTM, **Admin**, **Import Container**.
2. Choose this file.
3. Workspace: **Existing**, pick your working workspace (or create one).
4. Import option: **Merge**, then **Overwrite conflicting tags, triggers and
   variables**. On a first import into an empty container Merge and Overwrite
   behave identically; on a later import Overwrite keeps this file
   authoritative.
5. Review the preview list GTM shows, then confirm.
6. Nothing is live yet. Verify in **Preview**, then **Submit** and **Publish**.

## Verifying before publish

GTM Preview needs a page that actually loads the container, so use a local
production build rather than www (which does not load GTM until the code
change is deployed):

```bash
NEXT_PUBLIC_CMS_URL=https://cms.cleanstart.com NEXT_PUBLIC_GTM_ID=GTM-TBDDZW9K \
  pnpm --filter @cleanstart/web build
pnpm --filter @cleanstart/web exec next start --port 3107
```

Then connect GTM Preview to `http://localhost:3107` and walk through the checks
in `docs/superpowers/plans/2026-09-18-gtm-tag-migration.md`, Task 8.

## Regenerating

The file was generated by a script that reads the event and parameter lists
from `apps/web/src/lib/analytics/track.ts`. It is small enough to hand-edit;
if you add an event, add its Data Layer Variable, Custom Event trigger and GA4
event tag together, or the parameter silently never reaches GA4.
